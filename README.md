# TicTac Universe

Локальная браузерная игра в формате современных крестиков-ноликов.

## Что уже есть

- 1 vs 1 на одном устройстве
- игра против AI
- поля 3x3, 5x5, 10x10
- условия победы 3, 4 и 5 в ряд
- локальная статистика через localStorage
- адаптивный интерфейс
- готовность к GitHub Pages

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Деплой в GitHub Pages

Самый простой способ:

1. Залить проект в GitHub репозиторий
2. Запустить `npm install`
3. Запустить `npm run build`
4. Опубликовать содержимое папки `dist/` через GitHub Pages

Так как в `vite.config.js` стоит `base: './'`, проект хорошо работает как статическая сборка.
